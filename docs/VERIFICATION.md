# Проверки Orbit

## Обновление интерфейса 26 ноября 2026 года

- `pnpm check`: 8 тестов прошли, production-сборка создана. Проверка MongoDB пропущена в этом запуске; её отдельный результат приведён ниже.
- Новые проверки: выбор ближайшего шага с учётом назначения задачи, блокировок и конца дня; русские склонения и английские формы числа.
- В браузере проверены демовход, подсказки, открытие предложенной задачи, отправка комментария, пустой поиск и сброс фильтров, создание задачи на английском, сохранение и сравнение снимков.
- Проверены мобильная компоновка 390 × 844 и десктопная 1280 × 900, переключение RU / EN и мобильное меню. На проверенных страницах нет горизонтального переполнения документа и ошибок в консоли.
- Проверки интерфейса выполнены на отдельной демобазе внутри `.qa`. Рабочие данные не менялись.
- `pnpm format:check`: исходники соответствуют настройкам форматирования. Обновлены скриншоты обзора на русском и английском.
- Длинные тире убраны из исходников и документации. Оба языковых словаря имеют одинаковые ключи.

## Первоначальная проверка

Локальная проверка завершена 4 ноября 2026 года на Windows.

| Проверка | Результат |
| --- | --- |
| `pnpm test` | 6 общих тестов успешно; MongoDB-тест запускается отдельно или при заданном `MONGODB_TEST_URI` |
| `pnpm test:mongo` | Успешно с настоящей MongoDB 7.0.43: сохранение, повторное открытие, агрегации, индексы и неизменность снимков |
| `pnpm build` | Production-сборка Vite создана |
| `START-ORBIT.cmd` | Собирает интерфейс и запускает API на localhost |
| Браузер RU / EN | Демовход, поиск, создание и редактирование задачи, завершение со 100% прогресса |
| Снимки | Создание через форму, сохранение показателей и сравнение с исходным снимком |
| Мобильный вид 390 × 844 | Меню, доска задач, фильтры и аналитика; горизонтальное прокручивание ограничено доской и таблицами |

Тесты API проверяют парольный вход, HttpOnly cookie, проверку Origin, доступ исполнителя только к своим разрешённым полям, запрет циклов зависимостей, валидацию дат и прогресса, комментарии, каскадное удаление и сохранение на диске. Тесты общих модулей проверяют веса прогресса, конец дня дедлайна, соответствие языковых словарей и защиту CSV от формул.

Docker Compose и GitHub Actions были настроены, но не запускались в рамках этой локальной проверки.
